# coffee-cooling-simulator

Version 1.0

An interactive simulator based on Newton's Law of Cooling, developed with HTML, CSS and JavaScript.

This is my first complete scientific web application and also my first project written entirely in English, including the code structure, variables and interface.

📖 Project Overview

The simulator predicts how a cup of coffee cools over time using Newton's Law of Cooling, displaying both the numerical results and a dynamic temperature graph.

The objective of this project was not only to simulate a physical phenomenon, but also to improve my web development skills while learning how mathematics can be transformed into an interactive application.
----------------------------
✨ Features

☕ Coffee cooling simulation using Newton's Law of Cooling
📈 Interactive Chart.js temperature graph
🌡 Real-time temperature calculations
🎨 Dynamic graph colors based on coffee temperature
💨 Animated steam that changes according to temperature
🧊 Cooling status indicator (Hot, Warm or Cold)
📐 Newton's Law equation displayed inside the application
📐 Mathematical Model

Newton's Law of Cooling:
T(t) → Temperature after time t
Ta → Ambient temperature
T0 → Initial temperature
k → Cooling constant
t → Time

!! Challenges During Development !!

The most difficult part of the project was designing the coffee cup entirely with CSS.

Instead of using images or SVG graphics, every component of the cup was created manually using CSS properties such as:

border-radius
pseudo-elements
gradients
shadows
positioning
layering (z-index) ( why not SVG? = I wanted to practise my skills with CSS )

One of the biggest problems was making the coffee surface blend naturally with the rim of the cup. Several CSS techniques were tested before finding a solution that visually hid the unwanted rectangular edges and produced a convincing result.

This challenge became an excellent exercise for me to understanding how CSS rendering works.
